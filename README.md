# 👶 宝宝记录 —— 新生儿喂养 / 尿布 / 补剂记录

一款给新生儿家庭用的轻量记录 App，**无需联网、无需注册、数据保存在本机**。
本文件夹包含两个版本，按需选择：

| 版本 | 文件 | 怎么用 | 特点 |
|---|---|---|---|
| **A. 网页版（推荐先用）** | `index.html` + `icon.png` | 传到 iPhone，Safari 打开 → 添加到主屏幕 | ✅ 今天就能用，零安装，全屏像原生 App |
| **B. 原生 iOS 版** | `ios/NewbornLogApp.swift` | 用 Xcode 编译安装到 iPhone | ✅ 真·App，需 Mac + Xcode + Apple ID，见 `ios/README.md` |

两个版本功能一致：
- 🍼 **喂养**：母乳亲喂（左右侧 + 时长 + 计时器）/ 储存奶（奶量 ml + 冷冻/冷藏/常温/现挤状态）/ 配方奶（奶量 ml）
- 🧷 **大小便**：小便 / 大便 / 都有；大便性状（正常/稀水/干硬）、颜色（黄/金黄/绿/棕/黑/其他）、量
- 💊 **补剂**：名称 + 剂量（维生素D、AD、**维生素K1**、铁剂、益生菌、DHA 快捷按钮）
- ⏰ 每条记录都带**时间**（默认当前时间，可改），另有备注
- 📊 每日统计（喂养次数/亲喂时长/奶量、尿便次数、补剂项数）+ 时间线，可翻看历史日期
- ✏️ 点击记录可修改 / 删除
- 📤 一键导出备份 / 📥 导入恢复（防丢数据）

## A. 网页版：安装到 iPhone（5 分钟，无需任何账号）

> 原理：iOS 的「添加到主屏幕」功能把网页变成一个全屏、带图标、可离线用的"假 App"。
> 因为整个 App 只有一个文件、数据存本机，所以打开后**不需要网络**。

**第 1 步：把两个文件传到 iPhone**

任选一种方式（都是全家桶自带，不需要装任何东西）：
- **隔空投送（AirDrop）**：Mac/iPhone 上选中 `index.html` 和 `icon.png` → 共享 → 隔空投送 → 选目标 iPhone
- **微信**：电脑/手机上把两个文件发给「文件传输助手」，在 iPhone 上打开后点「用其他应用打开」
- **iCloud 云盘**：把文件拖进 iCloud Drive，iPhone 的「文件」App 里就能看到
- **邮件**：作为附件发给自己，iPhone 邮件里点开

⚠️ 两个文件都要传，并且要放在**同一个文件夹**里（`icon.png` 只是图标，忘了传也能用，但图标会变成网页截图）。

**第 2 步：在「文件」App 里打开**

iPhone 上打开「文件」App → 找到 `index.html` → 点一下，会自动用 Safari 打开。

**第 3 步：添加到主屏幕（关键一步）**

1. 点 Safari 底部的**分享按钮**（方框 + 向上箭头）
2. 在菜单里找到 **「添加到主屏幕」**（没有的话往下滚一屏或点「编辑操作」）
3. 名字可改成「宝宝记录」→ 点右上角**「添加」**

✅ 完成！现在主屏幕上有了一个 🍼 图标，点开就是**全屏 App**，以后都在这里打开使用。

**第 4 步：立刻做一次数据保险（强烈建议）**

打开 App → 右上角 ⚙️ → **导出备份** → 复制 → 粘到备忘录保存。
以后每周备份一次；换手机、清 Safari 数据前一定要先备份，再在新手机上 **导入恢复**。

## 常见问题

**Q：数据存在哪里？会丢吗？**
存在这台 iPhone 的 Safari 本地存储里。正常情况下不会丢，但：① 无痕模式（隐私浏览）下无法保存（App 顶部会出现红条警告）；② 卸载微信/清理 Safari 网站数据可能清掉。所以每周导出备份到备忘录是最稳的做法。

**Q：没网能用吗？**
能。App 是单文件离线应用，所有功能（记录、统计、导出）都不需要网络。

**Q：换手机怎么迁移？**
新手机：传两个文件 → 添加到主屏幕 → ⚙️ → 导入恢复 → 粘贴旧手机导出的备份文本。

**Q：iPhone 弹出"是否允许"？**
全部点允许即可。App 不联网、不收集任何数据。

**Q：记录时间不对？**
时间取的是手机系统时间，每条记录在保存时都能手动改。

见 [`ios/README.md`](ios/README.md)。需要：Mac + Xcode（App Store 免费下载，约 15 GB）+ 你的 Apple ID。

说明：Apple 不允许"免签名直接安装"的安装包存在——任何 iPhone App 都必须经 Apple 签名。免费 Apple ID 签名的 App 有效期 7 天（重插一次手机即可续）；99 美元/年的开发者账号才能长期使用/上架/TestFlight 分发。
